# Raj Jaiswal - AI Full Stack Developer Portfolio 🚀

Welcome to the repository for my personal portfolio website! This project showcases my experience, projects, skills, achievements, and education as an **AI Full Stack Developer**.

## 🌟 Features

- **Modern & Interactive UI**: Premium, dark-themed cyber-aesthetic design built with React, TypeScript, and Three.js / R3F.
- **Smooth Animations**: Integrated with GSAP and Lenis for smooth scrolling, interactive 3D physics tech stack spheres, and reveal animations.
- **Dynamic Content**: Data-driven components managed via `config.ts` for quick updates to projects, work experience, education, skills, and achievements.
- **Downloadable Resume**: Built-in functionality to directly download Raj Jaiswal's latest PDF resume.
- **Responsive Layout**: Fully optimized for desktop, tablet, and mobile viewing.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.org/) + [Vite](https://vitejs.dev/)
- **3D & Physics**: [Three.js](https://threejs.org/), [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber), [@react-three/rapier](https://github.com/pmndrs/react-three-rapier)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: Custom CSS with modern property variables
- **Animations**: [GSAP](https://gsap.com/) & [Lenis Smooth Scroll](https://github.com/darkroomengineering/lenis)

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to `http://localhost:5173` in your browser.

## 📂 Project Structure

- `src/components/`: Contains all React components (Navbar, Landing, About, Career, Work, TechStack, Contact, etc.)
- `src/config.ts`: Central data configuration holding all resume information.
- `public/`: Static assets, 3D models, generated project visual mockups, logos, and downloadable resume.
